기기에 저장하는 정보

음악·효과음 볼륨, 진동·목표 표시 설정, 연습 완료 여부와 플레이 기록을 앱 전용 저장공간에 보관합니다. 플레이 기록에는 출격 수, 최고 질량·연쇄·규모·생존 시간, 발견한 진화 카드, 최근 출격과 빌드 구성이 포함됩니다. 설정을 유지하고 기록·결과·도감을 표시하기 위해 사용합니다.

외부 전송과 제3자 기능

현재 내부 테스트 버전은 사용자 계정·로그인, 광고, 인앱결제, 분석 SDK 또는 자체 클라우드 저장 기능을 제공하지 않습니다. 게임 기록과 설정을 개발자 서버에 전송하는 기능을 구현하지 않았습니다. 게임 진행을 위한 개인정보 입력을 요구하지 않습니다.

개인정보처리방침을 누르면 기기의 외부 브라우저에서 웹페이지를 엽니다. 브라우저와 웹 호스팅 서비스의 일반적인 접속 정보 처리는 각 서비스 정책을 따릅니다. Google Play·Android의 설치·업데이트·진단 기능 역시 해당 플랫폼 정책의 적용을 받습니다.

기기 기능과 권한

게임 피드백을 위해 진동 기능을 사용하며 앱 설정에서 진동을 끌 수 있습니다. 현재 Android 빌드는 인터넷·카메라·마이크·위치·연락처 권한을 요청하지 않고 Android 앱 자동 백업을 비활성화합니다. 기기 제조사나 사용자가 별도로 사용하는 전송·백업 도구의 처리는 각 도구의 정책과 설정을 따릅니다.

보관과 삭제

로컬 정보는 앱 전용 저장공간에 유지됩니다. Android 설정에서 앱 저장공간을 삭제하거나 앱을 제거하여 기기의 게임 기록과 설정을 삭제할 수 있습니다. 삭제 전 필요한 기록이 있는지 확인해 주세요. 브라우저·운영체제에 저장된 정보는 해당 서비스의 관리 방법을 따릅니다.

문의와 변경

직접 문의 메일을 보내면 사용자가 제공한 메일 주소와 문의 내용을 답변 및 지원 목적으로 처리합니다. 문의 정보의 삭제 등 개인정보 관련 요청은 위 이메일로 연락해 주세요. 앱의 정보 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 갱신합니다.
