기기에 저장하는 정보

모르켄은 게임을 이어갈 수 있도록 진행 단계, 게임 속 동전, 강화, 장착 상태와 약초 획득 여부를 기기의 앱 전용 저장공간에 저장합니다. 효과음, 애니메이션과 진동 설정도 같은 기기에 저장합니다. 이 정보는 게임 진행 복원과 사용자가 선택한 설정 적용에 사용됩니다.

수집과 외부 전송

현재 싱글플레이 버전은 앱 계정이나 로그인을 사용하지 않으며, 개발자 서버로 게임 기록을 수집하거나 전송하지 않습니다. 이 버전에는 활성 광고, 인앱 결제, 이용 분석 및 추적 기능이 없으며 인터넷 권한을 요청하지 않습니다. 협동 기능은 비활성화되어 있습니다.

사용자가 지원 이메일을 직접 보내는 경우 Alan Works는 회신과 문의 처리를 위해 이메일 주소와 사용자가 제공한 내용을 받습니다. 문의에 불필요한 개인정보를 포함하지 마세요.

권한과 Android 백업

진동 권한은 사용자가 활성화한 게임 진동 피드백에 사용됩니다. Android 앱 백업은 허용하지 않도록 설정되어 있습니다. 사용자가 직접 수행하는 데이터 복사나 운영체제·기기 제조사의 이전 기능은 해당 기능의 설정과 정책을 따릅니다.

보관과 삭제

진행 기록과 설정은 앱을 사용하는 기기에 보관됩니다. 전체 로컬 데이터를 지우려면 Android 설정에서 앱 → 모르켄 → 저장공간 → 데이터 삭제를 선택하세요. 기기에 따라 메뉴 이름이 다를 수 있습니다. 앱을 제거해도 앱 전용 로컬 데이터가 삭제됩니다. 데이터를 삭제하면 저장된 게임 진행과 설정을 복원할 수 없습니다.
