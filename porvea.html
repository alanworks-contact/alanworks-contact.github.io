솔로 게임과 기기 내 정보

현재 버전은 회원가입이나 개인 계정 로그인을 요구하지 않습니다. 솔로 원정과 연출·소리 설정은 실행 중 메모리에서 처리됩니다. 앱을 완전히 종료하면 솔로 원정은 새로 시작됩니다. Android 앱 자동 백업은 사용하지 않도록 설정되어 있습니다. 앱에는 광고·결제·분석 SDK를 통한 전송 기능이 포함되어 있지 않습니다.

선택적인 온라인 협동

솔로 플레이에는 협동 서버 연결이 필요하지 않습니다. 협동을 선택하고 서버 주소를 입력하면 방 생성·참가·재접속을 위한 방 및 세션 식별값, 임의의 재접속 인증값, 참가 위치, 준비 상태, 주사위·체력·보상과 같은 게임 상태 및 게임 행동이 해당 서버로 전송됩니다. 함께 참여한 플레이어는 협동에 필요한 게임 상태를 볼 수 있습니다. 앱은 이 기능을 위해 이름, 이메일, 연락처, 위치, 광고 식별자를 요구하지 않습니다.

외부 서버 연결은 인증서를 확인하는 암호화된 WSS를 사용합니다. 기기 내부 루프백 연결은 예외입니다. 선택한 서버 운영자는 연결 IP 주소를 확인할 수 있습니다. 서버 주소를 직접 지정하는 방식이므로, 실제 접속 전에 운영자와 데이터 처리 방침을 확인하세요. 현재 테스트 버전에는 항상 제공되는 공용 협동 서버가 포함되어 있지 않습니다.

보관과 삭제

앱 내 협동 연결과 재접속 정보는 실행 중 메모리에서 사용됩니다. 연결을 종료하거나 앱을 완전히 종료하면 앱의 실행 세션이 종료됩니다. 서버 측 정보의 보관·삭제와 연결 로그 처리는 해당 서버 운영 환경에 따르며, 앱 삭제만으로 다른 운영자의 서버 기록이 삭제되지는 않습니다. Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 기기의 앱 전용 데이터를 삭제할 수 있습니다.
