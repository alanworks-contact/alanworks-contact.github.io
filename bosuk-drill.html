1. 처리하는 정보

보석폭파단은 자체 계정, 광고, 자체 분석 서비스 또는 개발자 원격 게임 서버를 사용하지 않는 MVP로 제공한다.

게임 진행, 복구 자원, 스테이지 완료 상태, 설정, 이용약관·개인정보처리방침 확인 버전, 선택적 알림 설정은 앱의 로컬 저장공간에 보관한다.

이 정보는 Alan Works의 서버로 전송하지 않는다.

2. 알림

사용자가 알림 받기를 선택한 경우 Android가 요구하는 알림 권한을 요청할 수 있다.

허용된 경우 기기 로컬 시간 기준으로 하루 최대 한 번, 점심 또는 저녁 시간대에 게임 플레이를 제안하는 로컬 알림을 예약한다.

이 기능:

  • 개발자 원격 푸시 서버를 사용하지 않는다.
  • 푸시 토큰을 수집하지 않는다.
  • 정확한 시각을 보장하는 exact alarm을 사용하지 않는다.
  • 운영체제의 절전·스케줄링 상태에 따라 전달 시각이 달라질 수 있다.

알림은 앱 설정 또는 Android 시스템 설정에서 끌 수 있고, 거부해도 게임을 이용할 수 있다.

3. 외부 정책 페이지

앱에서 이용약관, 개인정보처리방침 또는 지원 페이지를 열면 기기의 웹 브라우저에서 Alan Works GitHub Pages 사이트를 방문한다. 해당 웹 호스팅/브라우저의 네트워크 처리는 해당 제공자의 정책과 설정을 따를 수 있다.

Alan Works의 보석폭파단 정책 페이지에는 자체 광고, 분석 스크립트, 추적 쿠키 또는 폼 백엔드를 추가하지 않는다.

4. 권한

앱은 실제 기능에 필요한 최소 Android 권한만 사용한다.

사용하는 권한:

  • 알림 권한(Android 13 이상, 사용자가 알림 받기를 선택한 경우).
  • 햅틱/진동에 필요한 권한.
  • 기기 재부팅 뒤 선택한 로컬 알림을 다시 예약하기 위한 시스템 broadcast 권한.

위치, 연락처, 통화기록, 사진/동영상, 마이크, 카메라와 같은 사용자 콘텐츠 권한은 MVP에서 사용하지 않는다.

5. 보관과 삭제

앱 로컬 데이터는 사용자가 앱 데이터를 삭제하거나 앱을 제거할 때까지 기기에 남을 수 있다.

Android의 앱 정보에서 저장공간을 초기화하거나 앱을 삭제하면 앱 로컬 데이터를 제거할 수 있다.

보석폭파단은 자체 계정/클라우드 저장 서비스를 제공하지 않는다.

Android 자동 백업을 비활성화하며 개발자 서버에 저장 데이터를 백업하지 않습니다.
